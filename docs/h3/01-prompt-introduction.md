很多人把 H3 当成“又一个文生视频模型”，用 Seedance 或可灵那套关键词式写法去喂它，结果声音随机、镜头乱切。原因很简单：**H3 是音画一体生成模型，它期望的输入不是关键词列表，而是一份能按秒执行的分镜脚本加声音设计单。** 提示词写多细，成片就多稳。

## H3 和关键词式提示词的差别

传统视频模型的提示词是“画面标签”：主体、动作、风格、镜头术语，一行搞定。H3 的提示词是“时间线描述”：镜头从第几秒切到哪里、谁在说话、说的原话是什么、环境里有什么声音、观众能听到什么音乐。它同时产出画面和声音，所以你必须把“看得见的”和“听得见的”都写出来，一个字段都不能为空。

## 三个最常见的失败原因

| 症状 | 原因 | 纠正方向 |
| --- | --- | --- |
| 画面还行，声音完全不对路 | 没写整体声景和配乐字段，模型自由发挥 | 每条提示词写满三个核心字段 |
| 镜头切换混乱、内容塞不下 | 没有按时间线写切镜时间 | 用 [Shot N] 加递增时间戳组织正文 |

## 提示词的五种类型（按输入模式分）

“提示词分好多种类型”说的就是 H3 的五种输入模式。先看你手里有什么素材，再决定用哪种写法：

| 类型 | 你提供什么 | 什么时候用 |
| --- | --- | --- |
| T2VA 纯文本 | 只有一段文字描述 | 从零构建完整视听时间线 |
| I2VA 首帧图 | 一张图作为第 0 秒画面 | 用关键帧定调，让画面从图里“长”出来 |
| FL2VA 首尾帧 | 首帧加尾帧两张图 | 已知起点和终点，让模型铺中间的路径 |
| L2VA 尾帧 | 一张图作为最后一帧 | 画面要精确落在某个收尾构图上 |
| Ref2VA 多参考 | 多张图、参考视频、参考音频 | 角色场景一致性、声音复用的进阶玩法 |

前四种共用同一套三大字段结构，差别只是开头多一行“参考图对齐指令”；Ref2VA 用六段式结构，写法完全不同。本专区第 3 篇讲基础模式，第 4 篇讲全参考模式。

## 写之前的自检清单

- [ ] 视频总时长明确到秒，所有切镜时间都在时长以内
- [ ] 每个镜头都写了主体、构图和运镜
- [ ] 说话的人都编了号，并写了音色、语速等特征
- [ ] 台词逐字放进对话标签，保留原语言
- [ ] 整体声景成段写了环境声和动作声
- [ ] 背景音乐写明了乐器、速度、强弱变化，或明确写 N/A
- [ ] 画面中出现的文字用引号原样标注

【局部遮挡】背景音乐一项的字形上缘被截图拼接遮挡，以上按仍可辨识的文字整理。
